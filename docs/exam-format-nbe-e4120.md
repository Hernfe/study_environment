Theory difficulty: easy recall/identification; medium comparison, explanation, prediction and interpretation; hard multipart causal explanation/essay/sketch. Calculation difficulty: easy direct substitution; medium conversions/rearrangement/chaining; hard unfamiliar setup, formula selection and multistage reasoning. Methods difficulty: easy apparatus/mode recognition; medium method selection, trace explanation, controls/artifacts; hard source-supported design/troubleshooting and limitations. No arbitrary type quota. Preserve slide order within easy/medium/hard groups. Every question has two collapsed hints and a worked answer; written answers use self-review, never automated semantic grading.
